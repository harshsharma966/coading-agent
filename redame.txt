❓ Normal HTTP vs Streaming HTTP:
Normal API (media_type="application/json"): Request aayi ➔ Server ne JSON diya ➔ Connection turant CLOSE (band) ho gaya!

Streaming API (media_type="text/event-stream"): Yeh W3C ka official standard protocol hai jise SSE (Server-Sent Events) kehte hain. Yeh browser ko bolta hai:

"Sun browser! Connection ko band mat karna, pipe ko khula rakhna! Main thodi-thodi der mein naye words bhejta rahunga jab tak answer khatam na ho jaye!"

### 📌 AI Coding Agent mein STDOUT aur STDERR kya hain aur kyu zaroori hain?

Ek AI Coding Agent ke liye code aur terminal commands ka output samajhna sabse important hota hai. Computer ke andar har program ke paas baat karne ke do alag-alag channels (pipes) hote hain:

---

#### 1. STDOUT (Standard Output - Sahi Nateeja ✅)
- **Yeh kya hai:** Jab koi code ya command bina kisi error ke successfully chalti hai, toh uska output `STDOUT` pipe mein jaata hai.
- **Examples:** 
  - Python mein: `print("Hello World")`
  - Terminal mein: `git status`, `npm run build`, `dir` ka result.
- **Agent ke liye role:** Normal `print()` sirf aapki screen (monitor) par text phekta hai jisse AI Agent dekh nahi sakta. Hum `STDOUT` ko capture karke ek bucket mein jama karte hain taaki Agent usko padh sake aur user ko answer de sake.

---

#### 2. STDERR (Standard Error - Galti ya Crash ❌)
- **Yeh kya hai:** Jab kisi program mein koi error, exception, crash ya warning aati hai, toh computer usse alag pipe `STDERR` mein phekta hai.
- **Examples:**
  - `ZeroDivisionError: division by zero`
  - `ModuleNotFoundError: No module named 'fastapi'`
  - `fatal: not a git repository`
- **Agent ke liye role:** Jab code crash hota hai, tab Python `print()` nahi chalata. Error seedha `STDERR` mein chali jaati hai. Agent `STDERR` ko padhta hai taaki usse pata chale ki code kyu fail hua, aur woh khud uss bug ko fix kar sake (Self-Correction / Self-Healing).

---

#### 💡 Sirf `print()` se kaam kyu nahi chalta?
1. **`print()` khud `stdout` hota hai:** Python ke andar `print("abc")` actually parde ke peeche `sys.stdout.write("abc")` hi karta hai.
2. **Crash hone par `print()` chalta hi nahi:** Agar code mein error aayi, toh program crash ho jaata hai aur `print()` tak pahuchta hi nahi. Error sirf `STDERR` mein milti hai.
3. **Non-Python Tools (Git, NPM, Pytest):** Terminal ki commands (jaise `git`, `npm`, `pip`) koi Python code nahi hain, unke paas `print()` function nahi hota. Woh directly system ke `STDOUT` aur `STDERR` par baat karti hain.

---

#### 🎯 Ek Line Summary:
`STDOUT` program ka sahi nateeja padhne ke liye hai, aur `STDERR` uski galtiyan/errors pakad kar code fix karne ke liye hai.

export async function streamChatMessage(..., resumeDecision = null) {
  let url = `${API_BASE_URL}/chat/stream?thread_id=${encodeURIComponent(threadId)}`;
  
  if (resumeDecision) {
    // URL ban jaati hai:
    // http://127.0.0.1:8000/chat/stream?thread_id=default&resume_approved=true
    url += `&resume_approved=${encodeURIComponent(resumeDecision.approved)}`;
    if (resumeDecision.feedback) {
      url += `&resume_feedback=${encodeURIComponent(resumeDecision.feedback)}`;
    }

  // Backend ko POST request jaati hai

}

💡 Ek Line Mein Yaad Rakhne Ka Tarika:
interrupt(data): Yeh tool ke andar se data bahar fekta hai aur execution pause karta hai.
Command(resume=data): Yeh invoke/stream se data wapas andar bhejta hai aur wahi data interrupt() ka output ban jaata hai!
12:02 PM





interrupt() = Traffic Red Light 🔴 (Tool ke andar lagti hai gaadi rokne ke liye).
Command(resume=...) = Traffic Green Light 🟢 (Main function/invoker se di jaati hai gaadi aage badhane ke liye).
